# AI test data

Synthetic files for trying **Magic drop** and **Create plugin** by hand: drop a file (and,
for a binary format, its description) on the AI panel and compare what the AI finds with
the true contents below. Everything is generated by `tools/create_ai_demodata.py` with a
fixed seed. No real person's data is used, and the locations are a made-up loop.

```
python tools/create_ai_demodata.py            # everything, about 1 minute
python tools/create_ai_demodata.py --no-big   # without big/
```

The files under `big/` (about 80 MB) are ignored by Git; run the script to make them. The
unit tests don't use these files.

All recordings start at 2026-05-14 07:30:00 UTC unless the table says otherwise.

## Text formats

| File | Format | True contents | What it tests |
| --- | --- | --- | --- |
| `csv/weather_station_fi.csv` | CSV, Finnish locale, UTF-8 with BOM | 7 days at 10 min: temperature °C, air pressure hPa, humidity %, wind m/s. Local time (UTC+3) as `dd.mm.yyyy HH:MM` | Semicolons, decimal commas, non-ASCII headers with units in brackets, local time |
| `csv/bike_ride_power.csv` | CSV with `#` comment header | 90 min at 1 Hz: power W, cadence rpm, heart rate bpm, speed km/h. Unix ms timestamps. Device serial VL-0042-77 | Metadata in comments, 7 s gaps every 10 min, some empty heart rate cells, zero power while coasting |
| `csv/imu_200hz_short.csv` | CSV | 1 min at 200 Hz: acceleration x/y/z in g, angular rate x/y/z in deg/s; time in seconds | Units in column names, high rate |
| `json/run_session.json` | Nested JSON | 45 min run at 1 Hz: heart rate, speed m/s, cadence spm, altitude m, position [lat, lon]. Device Trackr Pulse 5, serial TP5-118-2093; 4 laps; start/pause/resume/stop events | Metadata, sample arrays with a shared interval, a GNSS track, laps and events |
| `json/home_sensors.jsonl` | JSON Lines | 2500 records at irregular times: living room temperature °C, front door open/closed, hall motion (true), hub battery V | Several series in one stream, numbers, states and events mixed, ISO times with offsets |
| `yaml/dive_log.yaml` | YAML | 46 min dive at 2 s: depth m (max about 26 m), water temperature °C. Dive 214, computer Deep 7, serial 0007-3321; gas switch to EAN50 at 2400 s | Nested metadata and a list of samples |
| `txt/logger_fixed_width.txt` | Fixed-width text report | 6 h at 5 s: CH1 voltage V, CH2 current mA, CH3 temperature °C, CH4 a 0/1 state. Logger XT-200, serial 004211 | Header block, units row, a few `---` missing values, footer line |
| `txt/serial_console.log` | Free-text device log | 40 min: heart rate bpm and RR ms every second; battery V and temperature °C every 10 s; WARN and ERROR lines | Values inside text, elapsed `[hh:mm:ss.mmm]` times, lines to skip |
| `gpx/trail_run.gpx` | GPX 1.1 | 60 min at 1 Hz: track, elevation, heart rate and cadence (steps per minute / 2) in Garmin TrackPointExtension | A standard format with extensions |
| `nmea/gnss_receiver.nmea` | NMEA 0183 | 20 min at 1 Hz: GGA (position, satellites, altitude) and RMC (speed in knots, course) | Checksums, `ddmm.mmmm` coordinates, two sentence types per second |

## Binary formats

Drop the data file together with its description, or the data file alone to see how far
the AI gets without it.

| Files | Description given as | True contents | What it tests |
| --- | --- | --- | --- |
| `binary/c_header/motion_logger.lgr` + `logger_format.h` | C header | 10 min at 50 Hz: acceleration x/y/z in mg, temperature (0.01 °C), air pressure (2 Pa units), flags (button, low battery). Serial MX-20-118842 | Packed little-endian structs, scaled integers, bit flags |
| `binary/markdown_spec/chest_strap.tlv` + `tlv_protocol.md` | Markdown document | 30 min: heart rate with 1 or 2 RR intervals (1/1024 s) per second, GNSS fix at 1 Hz, battery every 30 s, one text message. 9 frames have a wrong CRC and 4 have an unknown type; the stream starts mid-frame | Framing, CRC-16, variable-length payloads, resynchronising |
| `binary/python_spec/weather_mast.dat` + `baro_format.py` | Python reader | 45 min at 25 Hz: air pressure Pa, temperature (stored in 0.01 K, read as °C). Site "Mast 3" | Big-endian blocks, a 16-bit tick counter that wraps every 64 s |
| `binary/cpp_header/ride.pwr` + `power_meter.hpp` | C++ header | 60 min, about 4 samples/s at uneven intervals: torque Nm (from a float scale), cadence rpm (1/8 units), left/right balance %, coasting flag; power W derived (mean about 200 W). 4 laps; a second config record changes the crank length | Big-endian variable-size records, a float scale, a derived series, events |
| `binary/no_spec/fridge_logger.bin` | Nothing | 4 h at 10 s: temperature °C and humidity %. A 10-byte header: `FRDG`, uint16 column count (3), uint32 row count; then float32 rows of time s, temperature, humidity | Working out an undescribed format |
